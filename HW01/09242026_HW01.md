# In a hypothetical population, disease prevalence is 0.02, sensitivity is 0.90, and specificity is 0.95. Let D mean disease and T mean a positive test. Assume independent simulated people and the stated conditional test probabilities.

## a. Use np.random.default_rng(813109) and B=100000. First generate B independent uniforms to assign disease; then generate B new independent uniforms to assign positive tests with probability 0.90 for people with disease and 0.05 otherwise. Print the four counts TP, FN, FP, and TN, with clear labels. (3 points)

``` python
rng = np.random.default_rng(813109)
B = 100000

# Create disease vector
D = rng.random(B) < 0.02

# Create test vector:
p_pos = np.where(D, 0.90, 0.05) # Creates an array which assigns 0.90 to any row with TRUE in D and 0.05 to FALSE, etc.
T = rng.random(B) < p_pos

# Calculate counts:
TP = np.sum(D & T)
FN = np.sum(D & ~T)
FP = np.sum(~D & T)
TN = np.sum(~D & ~T)

print(f"True positives  (TP): {TP}")
```
